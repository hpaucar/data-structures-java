# Lista Doblemente Enlazada en Java

Este proyecto implementa una estructura de **lista doblemente enlazada** con diversas operaciones como inserción, eliminación, actualización y recorrido inverso.

## Estructura de archivos

- `Node.java`: Clase que representa un nodo doblemente enlazado.
- `Double_Linked_List.java`: Clase que implementa la lógica de la lista.
- `Main.java`: Contiene un menú interactivo para probar las operaciones de la lista.

## Cómo compilar y ejecutar

### Requisitos

- JDK instalado (Java Development Kit)
- Consola (Terminal, CMD o PowerShell)

### Compilación

```bash
javac *.java
```

Esto generará archivos `.class` correspondientes a cada clase Java.

### Ejecución

```bash
java Main
```

### Menú del programa

1. Insertar al inicio  
2. Insertar al final  
3. Insertar en posición  
4. Eliminar primero  
5. Eliminar último  
6. Eliminar en posición  
7. Actualizar nodo en posición
